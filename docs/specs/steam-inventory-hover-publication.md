This is a bounded contract for the shared inventory-shaped widget, its observed draw and input paths and its cached indices. It is not a census of arbitrary indirect writers or resource-defined behavior.

Three different observations coexist. The UI owner retains the scene selected by the last move dispatch. InventoryWidget draw independently evaluates geometry and publishes cell indices and a tab ordinal. Button-like children also receive draw-time visual changes based on their own freshly evaluated geometry. These observations do not constitute one synchronized hover value. A left-down listener can run on the newly dispatched target while reading a tab ordinal retained from an earlier draw.
