# Steam manual ground pickup: capacity, regional ownership and rejection sound

**FINAL / STABLE / HELD**

This addendum covers the original Steam native image with unpacked SHA-256 7AF18CB28C8BF848F355287428C6390B2EA2A682CA466190F5EB9859C5D6F244. The packaged reference and installed game image share SHA-256 A1EFBBD41EEB8DF08395C4D6511194D416CB70A14054B2A2000B9F5CDBCFA65B. All routine addresses below are RVAs of the unpacked image.

**Manual bag-check return.** Category zero returns false. A nonempty item whose automatic tab index is outside the existing tab array also returns false. Both returns precede all counter writes and leave the inventory unchanged. With an existing tab, an ordinary bag item returns true on finding an equal mergeable stack or at the end of the scan. This includes an empty tab and a tab where every existing slot is occupied. This check leaves ordinary bag entries and quantities unchanged. The stock helper has two exceptions that touch player gold or the auxiliary counter even though the caller is evaluating eligibility. Its success result is true in either case. Currency totals in a session therefore cannot be predicted from host receipts alone. See RVAs 0x8A381–0x8A407 and 0x8A470–0x8A4EF.

For an ordinary ingredient with three units in a bag, one eligible hover leaves three and queues no manual pickup. One accepted rising edge leaves three and puts one request at the front of the queue. A subsequent valid receipt for four matching units brings the stack to seven. With a missing target tab, both hover and rising-edge checks fail without changing the player's balances, and the press queues no request. These illustrate the distinction between input, request and settlement. See RVAs 0x8E304, 0x8E4AD, 0x8E4EA, 0x8E58F, 0x8E775 and 0xAA7AB–0xAA7C5.

**Canonical ownership query for category 0x18.** For subtypes other than 4, the native check constructs a new item identity. Its category at +0x00 is 0x18, its 32-bit subtype at +0x04 is the candidate's subtype, and its 32-bit region components at +0x0C and +0x10 come from player +0x150 and +0x154. Its 32-bit seed at +0x08, rarity byte at +0x14, 32-bit field at +0x18, material byte at +0x1C, all 128 customization bytes at +0x1D through +0x9C and customization count at +0x9D are zero. Padding is outside item equality. The query sums quantities of equal items across all inventory tabs and reports already owned if the signed total is positive. It excludes the cursor stack. For example, with no canonical item in a tab, a same-subtype item belonging to a different region does not satisfy this ownership query. See RVAs 0x5E8BD–0x5E972 and 0x4DF60.

**Subtype 4.** The independent instruction check shows that the ownership routine immediately returns true when its subtype argument is 4. It does not read the local player's tabs, region or cursor on this path. At the world eligibility caller, category 0x18 passes its subtype into that routine and a true result immediately returns false for ground eligibility. Thus an otherwise valid category 0x18/subtype 4 drop is rejected even for a local character with entirely empty bags. The caller has a separate earlier no-local-player path, outside this normal character interaction. See RVAs 0x5E8B1–0x5E8B8 and 0x2B82B5–0x2B82E9.

**When the cursor counts.** Three queries serve different decisions. The artifact eligibility query for category 0x17 compares the actual candidate against every tab and requires a total of at least one. The regional-special query for category 0x18 compares the canonical item described above against every tab. Both exclude the cursor. The carrying-limit query for its governed categories 01, 0B, 15 and 18 compares the actual candidate to the cursor item at player +0xA0C, counts cursor quantity at +0xA08 if equal, then adds matching tab quantities. Consequently, a canonical special held only on the cursor can pass world eligibility and still fail the later carry limit. See RVAs 0x5E780, 0x5E890 and 0x506A5–0x506F7.

**Manual rejection sound.** Both rejection paths use sound ID 0x34, mapped to human-voice01.wav in the Sounds directory. Both supply the local player's position from player +0x10, +0x18 and +0x20, base volume 1.0 and pitch 1.0. These are the parameters at the pickup caller. Audible output depends on the common sound routine's distance gate, listener-relative attenuation and pan, and the configured effects volume. A carrying-limit rejection emits the generic carry-limit text and sound. A failed bag check emits the same sound even for a tab without dedicated bag-full text. Merely displaying a full-item prompt does not enter either press-rejection sound call. See RVAs 0x8E540–0x8E56D, 0x8E6E0–0x8E709, 0xA0420 and 0xA3A40.

All observations are from the assigned original offline evidence. Actual speaker levels, live-frame counts and cumulative exceptional-counter behavior were not measured.
