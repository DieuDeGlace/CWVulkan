# Steam full-map controller-pan yaw: bounded original-evidence addendum

FINAL / STABLE / HELD. This addendum concerns the original Steam x64 image with preferred base 0x140000000, PE timestamp 0x5D93AB0D, and SHA256 7AF18CB28C8BF848F355287428C6390B2EA2A682CA466190F5EB9859C5D6F244. Evidence is restricted to original game decompiler/disassembly outputs and a direct read of the original image's angle-conversion constant. No existing held contract is amended.

The normal full-map controller-pan branch is in the main game update at RVA 0xA5A50. Its local admission checks begin at RVA 0xAB14F: the byte at game offset 0x668 and the byte at game offset 0x1958 must both be nonzero. A zero value in either byte skips this pan branch. These are the two direct admission flags for the cited branch; this addendum does not catalogue earlier admission conditions for the entire update routine or assign further UI-history semantics to either flag.

The yaw source used by that branch is the stored 64-bit floating-point value at game offset 0x1D90. It is loaded at RVA 0xAB1BA, narrowed to a 32-bit floating-point value at RVA 0xAB1C3, and supplied without a sign reversal to the yaw-rotation helper at call site RVA 0xAB1CE, whose target is RVA 0x13050. Thus this branch consumes the current stored yaw after narrowing, rather than taking its angle from the desired-yaw field at game offset 0x1DA8.

The current-versus-desired distinction is supported by a limited, directly relevant read of RVA 0xADCD0: the code loads desired yaw from game offset 0x1DA8 at RVA 0xADD87, subtracts the existing value at game offset 0x1D90 at RVA 0xADDA1, and later applies a scaled portion of that difference back to game offset 0x1D90, with the final store at RVA 0xADDFB. Calling offset 0x1D90 current/stored yaw and offset 0x1DA8 desired yaw describes this observed relationship; it is not a claim to recovered original field names. The broader camera pipeline and interpolation-factor derivation were not audited for this addendum.

The rotation call interprets the narrowed yaw in degrees. RVA 0x13050 multiplies the 32-bit input by the 32-bit constant at image RVA 0x42E520 before its sine and cosine calls. The original-image constant has bits 0x3C8EFA35 and is approximately 0.017453292, the degrees-to-radians scale. The narrowing therefore occurs before that conversion and before the trigonometric evaluation. No alternate yaw source, extra angular offset, or sign inversion appears between the cited load and this call. This statement is limited to that immediate argument path and does not re-audit the pan-vector math.
